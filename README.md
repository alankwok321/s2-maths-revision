# S2 Maths Exam Revision 中二數學考試溫習

Interactive revision guide for S2 Mathematics (Book 1B Ch 12; Ch 1, 2, 3, 4, 5, 11): animated lessons, unlimited practice, key points, Last 10 Minutes and a mock test. Bilingual (English / 中文).

- `index.html` – the built site (deploy this).
- `src/` – source. Rebuild with `python3 build.py`.
